## ⚙️ Instalación y ejecución

Clona este repositorio:

```bash
git clone https://github.com/Diego-Tardon/diego-portfolio.git
```

Accede al proyecto:

```bash
cd diego-portfolio
```

Instala las dependencias:

```bash
npm install
```

Ejecuta el servidor de desarrollo:

```bash
npm run dev
```

Genera la versión de producción:

```bash
npm run build
```
